# SF Investor Strategy: Python Water

Based on the provided context, outreach to SF investors will strictly adhere to the following rules:
- **No Email:** Use only LinkedIn, X, official forms, and warm intros.
- **Narrative Wedge:** Hardware (connected bottle) creates the daily behavior loop; software (AI hydration score + wearable data) creates venture scale.
- **Comparables:** Oura, WHOOP, Levels, Eight Sleep.
- **Guardrails:** No medical claims, no attachment in first touch, no exact raise amount, concise.
